# Ari Hendrawan portfolio

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users and purpose

Recruiters, hiring managers, and collaborators exploring Ari's risk, data, and product work. The primary journey is work → case study → resume or contact.

## Positioning

Risk & Data Scientist based in Jakarta. The English portfolio includes professional work, personal products, training projects, and experiments, each with its own evidence boundary.

## Constraints

- Preserve all 16 Markdown case studies and their URLs, roles, factual claims, and limitations.
- Demo videos exist only for Koii and KasMate; they use fictional local fixtures.
- Public benchmark figures are educational UCI results, never employer-model performance.
- No private customer or employer artifacts. No invented impact, testimonials, or implementation ownership.
- Next.js, TypeScript, plain CSS. No database, authentication, or new public APIs.
- This delivery is local only. Publishing remains a separate user decision.

## Approved direction

The user rejected the rigid Research Studio layout and approved a warmer, more personal, flowing design. See DESIGN.md for the implemented visual system.

## Accessibility

Navigation and core content work without JavaScript. Videos start only through user action. Reduced motion removes scroll enhancement, while manual video controls remain available. Resume has A4 print styling.
